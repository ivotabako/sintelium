# Sintelium logo

Selected by the owner: concept #1, row 1 / column 1 of the logo exploration board. The production artwork is a crisp SVG reconstruction of the geometric interlocking S/I concept, with a forest-green outer S and teal central I. It uses flat fills and transparent negative space instead of a raster crop, background, or exploration-board labels.

Assets:
- `public/images/logo-mark.svg`: normal mark for light surfaces.
- `public/images/logo-mark-reversed.svg`: light/mint mark for dark surfaces and the footer.
- `public/images/logo-horizontal.svg`: normal horizontal lockup.
- `public/images/logo-reversed.svg`: reversed horizontal lockup, transparent background.
- `public/favicon.svg`: mark on an off-white tile, inset to protect small-size legibility.
- `public/images/og-default.svg`: social card using the same mark.

The header/footer use the symbol with live website text. Standalone lockups use the system Segoe UI/Arial font stack. Keep the original SVG viewBox and use contain sizing; do not stretch the symbol or fill its negative space. Maintain clear space around the artwork. No logo-generation runtime or external image service is needed.
